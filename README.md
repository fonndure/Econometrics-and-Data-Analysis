# Портфолио учебных проектов по анализу данных и эконометрике

Студент НИУ ВШЭ — Санкт-Петербург, направление «Управление и аналитика в государственном секторе».  
В репозитории собраны учебные проекты по эконометрике, статистике и анализу данных.

## Проекты

### 1. Статистический анализ численности населения с высшим образованием (ТАБД)
- **Папка:** `TABD/`
- **Инструменты:** Python, CSV, описательные статистики
- **Что сделано:** обработка данных по 12 регионам, расчёт среднего, медианы, стандартного отклонения, построение рейтинга регионов.
- **Файлы:** [Ноутбук с проектом](TABD/Шалбаев-Проект-ТАБД.ipynb)

### 2. Эконометрический анализ: парная и множественная регрессия
*   **Папка:** `Econometrics/`
*   **Инструменты:** Excel (регрессионный анализ), Эконометрика, Статистика.
*   **Что сделано:** Построены парная и множественная модели по данным 85 регионов РФ. Проверена значимость (F- и t-критерии), проведено сравнение 6 нелинейных моделей.
*   **Результаты:** Выявлены ключевые драйверы спроса (инвестиции в основной капитал). Модель с наилучшей объясняющей способностью показала **R² = 0,87**. Построен прогноз с 95% доверительным интервалом.
*   **Файлы:** [Расчеты и модели в Excel](https://github.com/fonndure/Econometrics-and-Data-Analysis/tree/main/Econometrics)
